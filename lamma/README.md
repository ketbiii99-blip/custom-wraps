# لَمّة في بيت قنون 🏡☕

> **اللّمة تحلى بالتحدّي** — لعبة تحدٍّ عائلية عربية (RTL) بين فريقين، مصمّمة للعرض على **التلفزيون، الشاشة الكبيرة، اللابتوب والآيباد**.

بنيت بـ React + TypeScript + Vite، بدون أي خادم (backend). كل شي يشتغل في المتصفح، واللعبة تنحفظ تلقائياً في `localStorage` عشان تقدر تكمّلها بعدين.

---

## تشغيل المشروع

```bash
cd lamma
npm install
npm run dev      # للتطوير — يفتح على http://localhost:5173
npm run build    # نسخة الإنتاج داخل dist/
npm run preview  # معاينة نسخة الإنتاج
```

> للعرض على التلفزيون: شغّل `npm run dev -- --host` وافتح عنوان الجهاز من متصفح التلفزيون/الآيباد، أو ارفع مجلد `dist` على أي استضافة ثابتة (Netlify / Vercel / GitHub Pages).

## طريقة اللعب

| الشاشة | الوصف |
| --- | --- |
| **الرئيسية** | شعار متحرّك + «يلا نبدأ» + «كمّل اللعبة» (يظهر فقط لو فيه لعبة ما خلصت) |
| **اللاعبين** | «من موجود في اللّمة؟» — أضف الأسماء، و«قسّمنا عشوائي» يقسّمهم فريقين |
| **الفرق** | سمِّ الفريقين وانقل اللاعبين بينهم بنقرة |
| **الفئات** | «اختاروا علومكم» — كل فريق يختار ٣ فئات (المجموع ٦) أو «اختيار عشوائي» |
| **المساعدات** | كل فريق يختار ٣ مساعدات من ٦ |
| **اللوحة** | ٦ أعمدة × (٢٠٠،٢٠٠،٤٠٠،٤٠٠،٦٠٠،٦٠٠) = **٣٦ سؤال** + نتيجة الفريقين تحت |
| **السؤال** | يفتح ملء الشاشة: مؤقّت ٣٠ ثانية، مساعدات، «أظهر الإجابة»، ثم ✓ / ✕ |
| **النهاية** | «كفو! 🏆» + الفريق الفائز + قصاصات ملوّنة + «لعبة جديدة» / «إعادة نفس الفئات» |

### المساعدات (كل وحدة تنستخدم مرة واحدة)

| المساعدة | الأثر |
| --- | --- |
| **فزعة** 🤝 | يحق للفريق يطلب مساعدة من شخص حاضر |
| **خذ راحتك** ⏳ | +٣٠ ثانية على المؤقّت |
| **يا تصيب يا تخيب** 🎯 | فرصتين للإجابة بدل وحدة |
| **حوّلها عليهم** 🔁 | السؤال ينتقل للفريق الثاني — وإذا جاوبوا غلط **ينخصم** منهم قيمة السؤال |
| **دبّلها** ✖️ | مضاعفة نقاط السؤال |
| **علوم قنون** 💡 | يكشف تلميح السؤال |

### اختصارات للمقدّم (داخل شاشة السؤال)
- `مسافة` — إيقاف/تشغيل المؤقّت
- `Enter` — إظهار الإجابة

## ✍️ وين أضيف أسئلتي؟

عندك طريقتين — كلها تشتغل مع بعض:

### ١) من لوحة التحكم (الأسهل) — `#/admin`

افتح `http://localhost:5173/#/admin` (أو `رابط-الموقع/#/admin`، وفي الرئيسية فيه رابط صغير «⚙︎ لوحة الأسئلة»).

من هناك تقدر:
- تضيف / تعدّل / تحذف **فئة** (اسم، وصف، رمز إيموجي أو مسار صورة)
- تضيف / تعدّل / تحذف **سؤال** (الفئة، النقاط، النوع، السؤال، الإجابة، التلميح)
- **ترفع صورة** للسؤال أو تحط مسار/رابط، وتضيف **رابط صوت** أو **فيديو**
- **تصدّر** كل البنك كملف JSON، و**تستورد** ملف JSON
- ترجّع الأسئلة الأصلية وقت ما تبي

> تعديلات اللوحة تنحفظ في `localStorage` لهذا الجهاز/المتصفح فقط. عشان تخليها دائمة للجميع: صدّر JSON، وافصل محتواه إلى `src/data/categories.json` و `src/data/questions.json`.

### ٢) بتعديل ملفات JSON مباشرة (للنسخة الدائمة)

**فئة جديدة** في `src/data/categories.json`:

```json
{
  "id": "ganoun_cars",
  "name": "سيارات العيلة",
  "description": "منو صاحب هالسيارة؟",
  "icon": "🚗"
}
```
> `icon` يقبل إيموجي، أو مسار صورة مثل `/assets/cars.png`.

**سؤال جديد** في `src/data/questions.json`:

```json
{
  "id": "ganoun_cars_200_1",
  "category": "ganoun_cars",
  "points": 200,
  "type": "text",
  "question": "منو أول واحد في البيت اشترى سيارة؟",
  "answer": "بوقنون",
  "hint": "أكبرهم",
  "media": null
}
```

**قواعد مهمة:**
- `category` لازم يطابق `id` الفئة بالضبط.
- `points` وحدة من: `200` أو `400` أو `600`.
- كل فئة تحتاج **سؤالين على الأقل لكل مستوى** (٦ أسئلة) عشان تظهر جاهزة في شاشة الاختيار — لوحة `#/admin` تبيّن لك العدّاد `٢٠٠ / ٤٠٠ / ٦٠٠`.
- لو حطيت أكثر من سؤالين بالمستوى الواحد، اللعبة تختار **عشوائياً** منهم كل جولة — وهذي طريقة ممتازة تخلي اللعبة ما تتكرر.
- `id` لازم يكون فريد لكل سؤال.

## 🖼️ وين أحط الصور والصوت والفيديو؟

حطّ الملفات في `public/assets/` وبعدين نادِها بالمسار `/assets/...`:

```
lamma/public/assets/
├── grandpa.jpg
├── song-clip.mp3
└── wedding.mp4
```

```json
{
  "id": "who_is_this_400_1",
  "category": "who_is_this",
  "points": 400,
  "type": "guess_the_person",
  "question": "منو هذا؟",
  "answer": "بوقنون قبل ٤٠ سنة",
  "hint": "شوف الشارب",
  "media": {
    "image": "/assets/grandpa.jpg",
    "answerImage": "/assets/grandpa-today.jpg"
  }
}
```

أمثلة الصوت والفيديو:

```json
"media": { "audio": "/assets/song-clip.mp3" }
"media": { "video": "/assets/wedding.mp4" }
```

> تقدر بعد تستخدم روابط خارجية (`https://...`) بدل الملفات المحلية.
> ورفع الصور من لوحة `#/admin` يخزّنها داخل المتصفح مباشرة (base64) — عملي للتجربة، بس للصور الكثيرة خلّها في `public/assets` أخف وأسرع.

## ❓ أنواع الأسئلة المدعومة

| النوع | الاستخدام |
| --- | --- |
| `text` | سؤال نصّي عادي |
| `image` | سؤال مع صورة (`media.image`) |
| `audio` | مقطع صوتي (`media.audio`) — يشتغل تلقائياً |
| `video` | مقطع فيديو (`media.video`) |
| `multiple_choice` | يعرض `choices` كخيارات أ/ب/ج/د |
| `guess_the_person` | «منو هذا؟» — صورة + إجابة (وصورة إجابة اختيارية) |
| `guess_the_image` | «خمّن الصورة» — صورة مقرّبة |

المحرّك مبني عشان يتوسّع: لإضافة نوع جديد أضفه في `QuestionType` داخل `src/types.ts`، وأضف طريقة عرضه في `src/screens/QuestionView.tsx`.

## 💾 الحفظ والاستئناف

- اللعبة الجارية تنحفظ بعد كل خطوة تحت مفتاح `lamma:game:v1`.
- بنك الأسئلة المعدّل ينحفظ تحت `lamma:bank:v1`.

- خانة السؤال اللي انلعبت تصير **معطّلة ومعلّمة ✓** وما تنعاد.
