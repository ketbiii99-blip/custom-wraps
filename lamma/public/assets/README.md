# ملفاتك هنا 📁

حطّ في هذا المجلد صور وأصوات وفيديوهات أسئلتك، وبعدين نادِها من الأسئلة بالمسار `/assets/اسم-الملف`.

مثال:

```
public/assets/grandpa.jpg   →   "media": { "image": "/assets/grandpa.jpg" }
public/assets/clip.mp3      →   "media": { "audio": "/assets/clip.mp3" }
public/assets/video.mp4     →   "media": { "video": "/assets/video.mp4" }
```

تقدر بعد تستخدم رموز الفئات كصور: حط `/assets/cars.png` في حقل `icon` داخل `src/data/categories.json`.
