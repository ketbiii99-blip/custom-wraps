# جسر المقطع | حكاية تعبر الزمن

A 30-second vertical motion film about Al Maqta Bridge, Abu Dhabi. It is built
in Remotion (React), and every frame is rendered from code.

- 1080 × 1920, 30 fps, 900 frames, H.264 + AAC
- Composition id: `AlMaqta`

## Two cuts

- **`AlMaqtaReel`**: the fast cut for Reels, TikTok and Shorts. It runs at 120 bpm and every cut, word slam and camera punch lands on the beat grid. Code is in `src/reel/`, and the soundtrack comes from `scripts/reel_score.py`.
- **`AlMaqta`**: the original slow, cinematic cut, described in the sections below.

## Run it

```console
npm i
npx remotion studio        # live preview at http://localhost:3000/AlMaqta
npx remotion render AlMaqtaReel out/al-maqta-reel.mp4 --codec=h264 --crf=16
npx remotion render AlMaqta out/al-maqta-bridge.mp4 --codec=h264 --crf=16
```

`remotion.config.ts` points Remotion at a pre-installed headless Chrome. If that
path doesn't exist on your machine, delete the `setBrowserExecutable` line and
Remotion will download its own browser.

## Project layout

- `src/lib.ts`: timeline, easing, and the shared geometry of the real bridge
- `src/scenes/`: one component per world (scenes 05 and 06 share one continuous shot)
- `src/components/`: film grain, damage, motes, and the page peel
- `references/`: the visual reference boards provided for the film
- `scripts/prepare-assets.sh`: rebuilds every image, texture and the score from `references/`

Fonts (OFL, from Google Fonts): Aref Ruqaa, Amiri, Reem Kufi, Alexandria, Cormorant Garamond.
